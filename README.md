# Emerald SMP

Foundation plugin for Paper 1.21.11.

## Stage 1
- Clean modular plugin structure
- Configuration foundation
- Centralized message formatting
- /emerald
- /emerald reload
- emerald.admin permission
- UUID-based persistent player data

No economy, shops, orders, homes, teams, bounties, crates, or other gameplay systems are included in Stage 1.\n\n## Java version compatibility\n- Paper backend remains 1.21.11\n- ViaVersion 5.12.0 is packaged separately for newer Java clients\n- See `docs/java-version-compatibility.md` for the connection architecture and installation notes.
